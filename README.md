# قيد · Qaid

**A Simple, Beautiful & Bilingual Expense Tracker for Omani Rial (OMR)**

Qaid is a lightweight and user-friendly expense tracker designed to help individuals manage their daily spending, monitor monthly budgets, and understand their financial habits.

With Arabic and English support, Qaid provides a simple experience for tracking expenses in Omani Rial (OMR).

## ✨ Features

- **Expense Tracking:** Track and review your daily expenses.
- **Multiple Time Views:** View spending summaries by day, week, month, and year.
- **Spending Analytics:** Visualize expenses through an interactive category donut chart.
- **Monthly Budget:** Set a monthly budget and monitor your spending progress.
- **Recurring Expenses:** Manage recurring monthly expenses.
- **CSV Export:** Download your expense records as a CSV file.
- **JSON Backup & Restore:** Back up your data and restore it whenever needed.
- **Bilingual Interface:** Switch between Arabic and English with full RTL/LTR support.
- **Light & Dark Mode:** Choose the theme that suits you.
- **OMR Currency Support:** Displays amounts using three decimal places.
- **Responsive Design:** Works on mobile phones, tablets, and desktops.
- **Offline Support:** Access the app offline after its first successful load.
- **Installable App:** Add Qaid to your home screen on supported devices.
- **Quick Tour:** A simple introduction to help new users get started.

## 🔒 Privacy & Data Storage

Your privacy matters.

- No account or registration is required.
- No backend server or database is used.
- No tracking or analytics services are included.
- All expense data is stored locally in your browser using `localStorage`.
- Your data is not automatically synchronized between devices.

**Important:** Clearing your browser's site data may permanently delete your saved expenses. Private or incognito browsing may also remove stored data when the session ends.

We recommend downloading a JSON backup regularly to keep your data safe.

## 🚀 Getting Started

Qaid is a static web application built with HTML, CSS, and JavaScript. No build process or installation is required.

### Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

### Deploy with GitHub Pages

1. Create a new repository on GitHub.
2. Upload all project files and folders.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder.
6. Click **Save**.
7. Wait for GitHub Pages to publish your website.

Your Qaid app will be available through your GitHub Pages URL.

### Install on Your Device

- **Android:** Open the published website in a supported browser and use the install option when available.
- **iPhone:** Open the website in Safari, tap Share, then select **Add to Home Screen**.
